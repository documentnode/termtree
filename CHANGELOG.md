## 1.0.0 (Beta) — first public beta

TermTree's first public beta gives every terminal and AI agent a place on one live mind map, so you
can run work in parallel without losing track of what needs you.

- **Task map** — Plan work as a tree of task nodes, then launch a terminal into a node when you're
  ready. Pan, zoom, drag to reorganize, collapse a finished branch, and choose from eight tree
  layouts.
- **Live status** — Every node shows whether it is running, idle, waiting for input, or has failed,
  so nothing quietly gets stuck in the background. A chime and waiting-first cycling take you
  straight to whatever is blocked on you.
- **Real terminals** — Each task node opens a real PTY-backed terminal in its own project directory
  — run shells, servers, and tests, or launch Claude Code, Codex, or any other CLI. Search within a
  terminal, keep related shells side by side or stacked, and pick up your shell history as usual.
- **Agent awareness** — TermTree recognizes Claude Code and Codex sessions, marks the git worktree
  each one is working in, and offers to resume a session where you left off.
- **The terminal is your file explorer** — Click any file path your tools print, even one wrapped
  across lines, to open it beside the session that produced it. Edit it, review its changes against
  Git, then save when you're ready.
- **Preview and export** — Read Markdown as formatted prose with rendered Mermaid diagrams, preview
  HTML files as live pages, view PDFs and images, and export to DOCX.
- **Find anything fast** — Jump to a task by name, or open any file in the project with git status
  at a glance and a changed-files-only view.
- **Session restoration** — Return to the same tree, layout, terminals, scrollback, and recent files
  after restarting.
- **Make it yours** — Nine themes covering the map, terminal, and editor together, adjustable map
  styling, and 11 UI languages that switch live.
- **macOS, Windows, and Linux**, with quiet background updates that only interrupt you once a new
  version is ready to install.

This is a beta release: expect changes as we refine the workflow. The full local app is free for
personal use — download it at [termtree.com/download](https://termtree.com/download).
